# Buckaroo Poster: Code and References

This page accompanies Arnav Gupta's University of Utah SPUR research poster on
profiler-guided semantic-quality clustering in Buckaroo.

## Code

- [Buckaroo Visual Wrangler repository](https://github.com/shape-vis/BuckarooVisualWrangler)
- [Buckaroo VLDB 2025 demo paper](https://arxiv.org/abs/2507.16073)

The poster describes an active research extension of Buckaroo. It distinguishes
features that are implemented in the current research code from pilot results
and evaluation work that is still in progress. In particular, the prepared
human semantic-usefulness study is not reported as a completed result.

## How To Read The Poster Claims

- **Implemented** means the feature exists in the current research code.
- **Experimentally verified** means a preserved experiment or automated test
  supports the statement.
- **Pilot** means the result is useful evidence but is not yet a final
  human-labeled benchmark.
- **Planned** means the experiment design or review material exists, but the
  human evaluation is not complete.
